# CPSC 335 - Project 3
# Problem 2: Longest Common Subsequence
# Dyllan Cummings

Input: Two strings, text1 and text2
Output: Length of the longest common subsequence

1. Find the length of text1 and call it n.
   Find the length of text2 and call it m.

2. Create a table T with n + 1 rows and m + 1 columns.

3. Fill the first row and first column of the table
   with zeros (empty string has no common subsequence with another string).

4. Starting with the first character of text1, compare it with each character of text2.

5. For each pair of characters:

   a. If the characters match:
      - Take the value from the diagonally upper-left cell of the table and add 1.

   b. If the characters do not match:
      - Compare the value directly above the current cell with the value directly to its left.
      - Store whichever value is larger.

6. Repeat Step 5 until every character of text1
   has been compared with every character of text2
   and the entire table is filled.

7. Return the value in the bottom-right corner
   of the table. This is the length of the
   longest common subsequence.
